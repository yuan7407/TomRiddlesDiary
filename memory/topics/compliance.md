# 合规、密钥与 IP 防火墙

## IP 防火墙

### 禁止进入公开/分发面

未经授权的 `Harry Potter / Voldemort / Hogwarts / 霍格沃茨 / 魂器` 等元素不得出现在 App 名称、用户文案、图标、截图、关键词、营销或客服话术中。

### 当前内部占位

- 项目/仓库名与 Xcode 占位 bundle ID。
- gitignored 本地 persona。

这些只限私有、非分发面，不代表商业许可。正式注册 App ID、制作截图或 TestFlight 前必须复核并采用原创公开品牌。

### 门禁

- `scripts/ip_firewall_check.sh` 扫描 Git 已跟踪和未被 `.gitignore` 排除的候选文本。
- 内部策略面（`AGENTS.md`、`CLAUDE.md`、README、docs、memory、角色提示词）因必须讨论禁用词而跳过；公开面仍需人工检查 staged diff。
- 门禁同时确认 `Config/Secrets.xcconfig` 与 `Config/Persona.local.json` 未被 Git 跟踪。
- 二进制、虚拟环境、构建产物与 xcuserdata 不扫描，避免超时/误报。

## 模型密钥

- 永久 Key 不进入可分发客户端二进制、客户端可提取流量或 Git。
- 本地非分发 DEBUG 实验若获准直连：gitignored、最小权限/模型范围、额度/异常监控、build 永不分发。
- TestFlight/生产调用经安全后端；临时凭证也必须短 TTL、鉴权、限速和防滥用。

## 数据与隐私

- 日记默认端侧加密；提供记忆开关、上下文上限、一键遗忘和删除全部数据。
- 只发送完成请求所需的最少数据；生产日志不记录日记图像、提示词全文或凭证。
- “请求后删除”“不用于训练”“数据不出境”必须由最终区域、供应商条款/合同、日志与备份策略、服务端和客户端实现共同证明。
- 备案状态或选择国内区域不能单独证明全链路驻留。

## 发布前合规清单

- 成人定位与实际 App Store 年龄分级/门槛。
- 清楚披露 AI 身份和 AI 生成内容，不用世界观掩盖事实。
- 自残/危机识别与安全兜底；产品不宣称医疗诊断或治疗。
- 删除全部数据、关闭记忆、隐私政策与平台 privacy labels。
- 针对目标市场复核生成式 AI 标识、内容安全、跨境与平台审核要求。
- 营销视频、截图和描述必须与真实 App 体验一致。

## 监管信息边界

历史规划中的法规名称、日期、费用和平台条款只用于风险识别，不是法律意见；签约、TestFlight 或上架前必须查询目标市场与 Apple/供应商官方最新版，必要时咨询专业人士。
