# 架构决策日志

记录“做什么、为什么、排除了什么”；当前通用规则以根 `AGENTS.md` 为准。

## 项目由来与关键转折

- 初始灵感来自“会回应的魔法日记”，重构为成人向、涂鸦驱动、AI 用逐笔生长线条回应的 iPad 情感反思工具。
- IP 只可作为内部体验锚点；商业产品必须使用原创品牌与世界观。
- 用户明确选择涂鸦为核心模态，而不是复制文字对话。
- 原计划先脚本验证再建 App；当前折中为 Task 1 脚本预检 + 后续 App 内完整垂直切片，但每层证据必须分开解释。

## 笔画方案的完整语境

1. 魔法感是渲染/节奏属性，SVG 和图像抽骨架都能逐笔播放。
2. 模型直接 SVG 可能偏几何且不稳定；图像抽骨架会丢笔顺并产生分叉，两者都有代价。
3. 本地 StrokeEngine 统一负责笔顺、人性化和播放，因此源可以替换。
4. 10 组确定性夹具由同一有序几何生成 SVG/PNG，只适合比较管道损失，不适合判断模型创意或情绪回应。
5. 最终结论必须使用真实用户涂鸦与真实模型回应，由用户肉眼评审。
