## 模型与 Key 边界（2026-07-23 核对官方说明）

- Key 按区域区分；部分区域（北京、新加坡、东京、法兰克福等）调用需把 Workspace ID 放进 Base URL，接入时以实际账号页面为准。
- 永久 Key 不进入可分发 App；移动端正式调用经安全后端。官方建议由后端为不可信环境签发临时 Key（默认 60 秒，可配 1–1800 秒，且继承签发 Key 权限）。
- 参考：[Qwen 首次 API 调用](https://help.aliyun.com/en/model-studio/first-api-call-to-qwen)、[临时 API Key](https://help.aliyun.com/en/model-studio/application-obtain-temporary-authentication-token)。

## 合规底线

- **IP**：未经授权的 `Harry Potter / Voldemort / Hogwarts / 霍格沃茨 / 魂器` 等元素不得出现在 App 名称、用户文案、图标、截图、关键词、营销或客服话术。`scripts/ip_firewall_check.sh` 是门禁，不替代人工审查（内部策略文档因需讨论禁用词而跳过）。
- **隐私**：日记默认端侧加密；记忆开关、上下文上限、一键遗忘、删除全部数据；只发送必需最小数据；生产日志不记录日记图像、提示词全文或凭证。
- **发布前**：真实年龄分级；清楚披露 AI 身份与 AI 生成内容；自残/危机兜底且不宣称医疗诊断；隐私政策与 privacy labels；目标市场的生成式 AI 标识与跨境要求；营销素材与真实体验一致。
- 历史规划中的法规名称、日期与费用只用于风险识别，不是法律意见，签约/上架前须查官方最新版。
