# 模型选型：为什么是 Qwen（决策 8）

## 用户的硬约束

- 要**全球可调 + 中国免翻墙**。
- Gemini/GPT/Claude/FLUX 在中国大陆都要翻墙（防火墙决定，选型无法解决）。
- 能免翻墙的只能是国产厂商模型（上中国区商店本就要已备案国产模型）。
- **AI 回复含图像** → 接口必须支持图像**输出（生成）**，不只识图。

## 核实过的点（官方模型卡）

- **Qwen-Image**（2025.08 开源、Apache 2.0）同时做生成 + 编辑 + 理解，带 Canny 边缘与极简风格（契合抽骨架管道），中文文本渲染强。
- **DeepSeek 的 Janus-Pro** 虽能生成但仅 384px、研究级开源、非生产 API → 「DeepSeek 做图像主力」不成立，用户直觉对。

## 杀手锏

Qwen-Image 是**开源权重，可自部署到任意地区**——中国用户连国内节点、海外连海外节点，都不翻墙、不看厂商地区脸色。这是闭源模型给不了的。

## 落地方案

- 阿里云百炼（Model Studio / DashScope，中国区 + 国际区）托管起步；自部署托底。
- 海外若要更高画质，把 Gemini/FLUX 作可选升级挂在同一 `OracleProvider` 接口后。
- `OracleRouter` 按区域选端点（中国区/国际区/自部署），按分层选是否走海外升级。

## 分工

- **Qwen-VL / Qwen3-VL**: 读用户涂鸦（视觉理解）。
- **Qwen-Image**: 生成回应线稿（图像输出 + 编辑）。
- 线稿提示词统一约束：「干净的黑色线稿、白底、无阴影」以利抽骨架。

## ⚠️ 未核实项（定架构/签约前必须复核）

- 阿里云百炼**当前定价**。
- **国际区覆盖**范围。
- **「国际节点从中国能否免翻墙直连」**——这条尤其关键，直接影响是否需要自部署。
