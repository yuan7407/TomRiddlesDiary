# 笔画引擎与 riddle 借鉴

## 核心分工（铁律）

- **AI 层（Oracle）负责「画什么」**：文字 + 生成图像。
- **本地笔画引擎负责「像不像手画的」**：压感/收笔/速度/抖动/笔顺。
- 自然来自本地引擎的笔顺 + 压感 + 节奏，**不指望大模型直接吐好看的笔画**。

## 从爆火开源库 riddle 学到的（通用智慧）

> riddle = 病毒视频真身，跑在 reMarkable 墨水屏、用 Rust、文字对话、非商用 MIT 开源（所以它敢直接叫 Tom Riddle——恰恰反证商业版必须原创）。仓库：github.com/maximerivest/riddle（+ 兄弟库 quill）。

与文字/墨水屏无关、可复用的机制：

1. **分工**：AI 只回内容；「像手写/手绘、一笔笔长出来」在本地用确定算法做：渲染 → Zhang-Suen 抽骨架（瘦成单像素中心线）→ 理笔顺 → 逐笔重播。
2. **流式先落笔**：回复一句句流式返回，第一笔约 1 秒出现。→ 我们：文字先流式手写，图像并行生成后再画，盖住图像生成延迟。
3. **抬笔静置自动成页**（~2.8s），无「发送」键；「墨水淡入纸里」过渡。
4. **出错留在世界观内**：没网/没 key 时，「日记」用它的口吻把原因写在纸上，而不是弹报错。
5. **记忆**：本地纯文件、近几页随请求带上下文、手写指令召回旧页（「给我看看关于花园那页」）、一键遗忘、页数上限。
6. **笔即界面**：尽量少按钮。

## StrokeEngine 管道（本地）

```
渲染灰度 PNG
  → Skeletonizer(Zhang-Suen)     # 瘦成单像素中心线
  → StrokeTracer                 # 中心线 → 有序笔画（理笔顺）
  → StrokeHumanizer              # 压感 / 收笔 / 速度 / 抖动
  → CAShapeLayer strokeEnd 逐笔重播
```

## 两条笔画来源（Task 1 对比实验决定）

- **① 直接 SVG**：让大模型直接吐 SVG `<path>` 序列，拆成有序 stroke 逐笔画。快、零训练，但线条早期偏几何。
- **② 生成图抽骨架**：Qwen-Image 生成干净线稿 → 抽骨架 → 理笔顺。
- 两条都套压感/速度，**肉眼选源**。禁止提前拍板。

## 关键设计原则

矢量笔画非位图；不指望模型直吐好看笔画；体验优先于技术炫技；情感真实性（换一张涂鸦回应必须明显不同）；数据端侧加密、只发灰度 PNG、读完即删、一键遗忘。
