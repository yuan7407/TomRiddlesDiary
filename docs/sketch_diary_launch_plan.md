# 涂鸦日记 App｜验证管道与启动全流程

> 源想法文档拷贝（原 `~/Downloads/sketch_diary_launch_plan (1).md`）。这是本项目的灵感与全流程母本；活文档，随 Phase 0 结果迭代。价格/法规为 2026 年 7 月信息，签约或上架前务必复核官方最新版本。

---

> 一个成人向、以视觉/涂鸦为核心交互的情感反思工具。用户手写/手绘，AI 用**逐笔生长的手绘线条**回应。载体：iPad + 类纸膜。商业模式：免费层建立依恋 + 订阅解锁记忆与深度。
>
> 本文档分五部分：**Phase 0 验证管道**（先花一周证明魔法真实存在）→ **技术架构**（前端/后端/模型）→ **供应商与 backup 全表** → **合规与审核避雷** → **90 天启动路线图**。
> 每个关键决策都给了「主选 + backup」，避免单点依赖。

---

## 核心设计原则（写在最前面，贯穿全文）

1. **震撼来自体验，不来自欺骗。** 病毒视频可以极致美，但 App 交付的必须与营销所示一致——这是能不能上架、能不能投广告的生死线（见第四部分苹果 2.3 条款）。
2. **矢量笔画，不是像素图。** AI 的输出永远是「一串可被逐笔重绘的路径」，绝不是一张贴上来的位图。这是魔法感的技术命根子。
3. **成人定位是前提，不是选项。** 情感陪伴 + 未成年 = 2026 年全球监管靶心。所有设计从 day 1 按成人产品做。
4. **先验证最脆弱的假设，再投入。** 最脆弱的不是「能不能做出来」，是「AI 回的 sketch 到底动不动人」。Phase 0 只为回答这一个问题。

# 第一部分：Phase 0 — 一周验证管道（最重要）

**目标**：不做 App、不碰前端，用最粗糙的脚本证明「涂鸦进 / 涂鸦出」这条链路能产生让你自己起鸡皮疙瘩的东西。如果连你都不被打动，后面全部停手。**预算 ≈ ¥0（用你现有的 Claude Max + 少量 API 额度）。**

### 管道结构（四个模块）

```
[你手画的涂鸦 PNG]
      │
      ▼
① 理解层：多模态视觉模型读懂涂鸦语义 + 情绪
   输出：结构化 JSON（主体、情绪基调、隐含叙事）
      │
      ▼
② 生成层：语言模型根据情绪，生成"回应画面"的绘制指令
   输出：一串有序 SVG 笔画路径（stroke sequence），不是位图
      │
      ▼
③ 渲染层：把笔画序列逐笔"画"出来
   Phase 0 用最土的方式：Python 生成 SVG → 浏览器逐笔动画预览
      │
      ▼
④ 你的主观判断：这个回应，动人吗？
```

### 逐模块实现（Claude Code 一两天可搭）

**① 理解层**
- 输入：你用任意手写设备（甚至纸+手机拍照）画的情绪涂鸦，导出 PNG。
- 调用：多模态视觉 API，prompt 要它输出**结构化 JSON**而非散文。
- 主选模型：Gemini 3 Flash（多模态性价比标杆）。Backup：GPT-5 Mini 或 Claude Haiku 4.5。
- 关键点：Phase 0 就要试 3 个模型对**同一张涂鸦**的理解差异，这个对比本身就是选型依据。

**② 生成层（整个项目的技术核心）**
- 要模型输出的不是「一段话」，也不是「一张图」，而是**一串能被逐笔重绘的矢量笔画**。
- 三条实现路径：
  - **路径 A（推荐起步）**：让通用大模型直接输出 SVG `<path>` 序列，拆成有序 stroke 逐笔画。快、零训练，早期偏「几何」。
  - **路径 B（进阶）**：接专门的 sketch 生成研究模型（NeuralSVG / Sketchformer / SketchKnitter），线条更「手绘感」，但要自己跑、要工程整合。
  - **路径 C（绝不要用）**：文生图再矢量化。生成的是像素画，节奏和线条不是「人手画出来」的有序笔画，魔法当场穿帮。负样本。
- 主选：路径 A 起步验证，路径 B 作为产品化后提升线条美感的升级项。

**③ 渲染层（Phase 0 极简版）**
- Python 把笔画序列写成带 `stroke-dasharray` 动画的 SVG，浏览器打开就能看到「逐笔生长」。

**④ 判断**
- 画 10 张不同情绪的涂鸦（悲伤/焦虑/平静/愤怒/迷茫…），跑完整管道看回应。
- **通过标准**：至少 3-4 张让你「哦…」了一下。达不到，调 prompt 或换模型；连续失败 → 暂停重估。

### Phase 0 交付物
- 一个能跑的脚本 + 10 组「涂鸦→回应」样本。
- **副产品**：这些样本就是第一条病毒视频的原始弹药，且「名实相符」。

# 第二部分：正式技术架构（Phase 0 通过后）

### 2.1 前端（iOS App）

| 项目 | 主选 | 说明 / Backup |
|---|---|---|
| 语言/框架 | Swift + SwiftUI | Backup: React Native（手写延迟体验打折，不推荐做核心画布） |
| 手写画布 | PencilKit（苹果原生） | 免费、低延迟、压感/倾斜全支持，直接拿到笔画 stroke 数据 |
| 逐笔动画渲染 | Core Animation + CAShapeLayer 的 `strokeEnd` | 逐笔「生长」用系统级动画；复杂笔画可用 Metal |
| 类纸质感 | 物理贴膜 + UI 层降噪配色、暖色底、纸纹理 | 软硬结合 |
| 本地存储 | SwiftData / Core Data，日记默认端侧加密 | 隐私卖点 |

### 2.2 后端

| 项目 | 主选 | Backup |
|---|---|---|
| 应用后端 | Supabase（Postgres + Auth + Edge Functions） | Firebase / 自建 FastAPI + Postgres |
| 用户鉴权 | Supabase Auth / Sign in with Apple | — |
| LLM 调用编排 | 后端 model router：简单涂鸦→便宜模型，复杂情绪→贵模型 | OpenRouter 聚合 |
| 订阅/支付 | RevenueCat（封装 StoreKit） | StoreKit 2 直连 |
| 内容安全 | 生成前后各加一层 moderation | — |

### 2.3 模型分层策略（控 token 成本的命门）

| 用户层 | 理解层 | 生成层 | 记忆 | 目的 |
|---|---|---|---|---|
| 免费 | 便宜档（$0.25–0.5） | 轻量、单一人格、无记忆 | ❌ | 建立依恋 |
| 订阅 | 贵档（$2–3） | 更慢更用心、多人格/世界观 | ✅ 记得你 | 为「关系深度」付费 |

- 省钱杠杆：Prompt caching、Batch API、router 智能分流。
- **合规注意**：国行/中国大陆版必须用**已备案的国产模型**（通义/豆包/DeepSeek/GLM 等），不能内置境外 API。海外版才用 Gemini/GPT/Claude → 实际要维护两套模型通道。
  - （本项目已据此收敛为 Qwen 为主，见 `memory/topics/model-selection.md`。）

### 2.4 关于「记忆」
- 用向量数据库（pgvector / Pinecone / Weaviate）存历史涂鸦情绪摘要，回应时检索相关往事 → 「它记得你上周画的那场雨」。订阅核心价值 + 最强留存钩子。
- **红线**：加密、可一键删除（GDPR/COPPA 的 eraser button）、成人定位，三者缺一不可。

# 第四部分：合规与审核避雷（上线生死线）

### 4.1 苹果 App Review —— 最先撞的墙

| 风险条款 | 具体雷 | 规避动作 |
|---|---|---|
| 2.3 误导性营销 | 病毒视频呈现「真魔法纸」，App 实为 iPad 应用 → 素材与产品不符 | 视频把「iPad + 类纸膜的沉浸体验」作为卖点公开；App 内体验与素材一致 |
| 1.x 儿童安全 / 年龄分级 | 情感陪伴天然滑向青少年 | 明确成人定位，分级 17+，加年龄门槛 |
| 3.1.1 应用内购买 | 订阅必须走苹果 IAP | RevenueCat 规范接入；小开发者计划首年抽成 15% |
| 5.1.1 数据收集 | 日记是最敏感数据 | 隐私标签如实填写；端侧加密；最小化收集 |
| Sign in with Apple | 有第三方登录就必须提供苹果登录 | 直接上 |

### 4.2 情感陪伴 AI 监管（越浪漫，画像越危险）

2026 全球监管最高压类目。核心策略：**成人定位 + 清晰 AI 披露 + 危机兜底**，把自己划出「面向未成年人的 companion chatbot」射程。

| 法域 | 关键法规 | 动作 |
|---|---|---|
| 加州 | SB 243（2026.1.1）：AI 身份披露、休息提醒、自残防护、可被起诉 | AI 身份声明 + 自残/危机干预兜底 |
| 纽约 | S 9051：禁止向 18 岁以下提供伴侣聊天机器人 | 硬性年龄门槛，成人定位 |
| 联邦 | GUARD Act：强制年龄核验、自报生日无效 | 美分发需可靠年龄核验 |
| 联邦 | COPPA 2.0：保护年龄升至 17 以下、eraser button | 一键删除全部数据 |
| 欧盟 | AI Act 第 50 条：聊天机器人透明度；AI 内容标识 | 明确告知在与 AI 交互；内容标识 |
| 澳洲 | 2026.3.9 起强制年龄核验，自我申报无效 | 谨慎进入 |
| 中国 | 生成式 AI 算法+模型双备案；AI 生成内容标识办法；未成年人网络保护条例 | 国行用备案国产模型；开机声明+水印；防沉迷 |

> **设计张力**：披露义务会磨损沉浸仪式感。解法不是省略披露，而是**把披露设计得有仪式感**——开篇由「日记的灵魂」以世界观口吻自述非人属性，把合规变成叙事的一部分。

### 4.3 IP 避雷
- **Harry Potter / 伏地魔 / Tom Riddle / 汤姆·里德尔日记 = 华纳兄弟版权+商标，一个字都不能出现**在 App 名、图标、截图、关键词、广告文案、客服话术里。
- 必须**自建原创「会回应的日记」世界观**。
- （本项目对「Tom Riddle」项目名/bundle id/本地 persona 的已知情接受项，见 `memory/topics/compliance.md`。）

### 4.4 数据隐私架构（day 1 设计，不能后补）
- 日记内容默认端侧加密，云端只存必要的情绪摘要向量，不存原文。
- 传输加密、跨境合规（国行数据不出境）、一键删除。
- 这套架构本身就是营销卖点：「你的日记，只属于你——端侧处理，永不留云。」

# 第五部分：90 天启动路线图

| 阶段 | 时间 | 目标 | Go/Kill |
|---|---|---|---|
| Phase 0：魔法验证 | 第 1–2 周 | 涂鸦进/出脚本，10 组样本 | ≥3–4 组动容 → Go；连续失败 → Kill |
| Phase 1：可玩 Demo | 第 3–6 周 | SwiftUI + PencilKit 画布 + 管道打通，逐笔动画 | 真 iPad + 类纸膜完成一次「画→回应」 |
| Phase 2：病毒素材 + 落地页 | 第 7–8 周 | 1–2 条名实相符视频 + 等待名单 | 收集自然反馈与注册意向 |
| Phase 3：TestFlight 内测 | 第 9–12 周 | 加订阅、记忆、合规兜底 | 观察 7 日/30 日留存 |
| 决策点 | 第 12 周末 | — | 30 日留存 & 付费意向达标 → 上架 + 投放 |

### 关键指标（别自欺）
- **不是**下载量、点赞（虚荣指标）。
- **是** 30 日留存 和 免费→付费转化率。

### 独特杠杆
- 护城河不是「AI 会回应」，而是**「把 AI 藏进有仪式感的媒介、用逐笔生长的手绘线条回应情绪」**这个体验设计——需要审美、叙事、交互编排。
- sketch 模态绕开了字体授权、多语言识别、墨水屏卡脖子三大坑。

### 三件在职身份必须先办的事
1. 核查竞业限制与知识产权归属条款（尤其岗位涉及 AI 工具与创意产出）。
2. 主体：以个人开发者还是新设公司上架（建议独立主体）。
3. 分发市场排序：先海外或先国行，不要一上来全球；先做单一语言、单一市场的最小合规版本试水。
