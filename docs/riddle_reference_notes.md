# riddle 参考笔记（技术借鉴）

> 来源：github.com/maximerivest/riddle（+ 兄弟库 quill）。以下要点整理自规划交接文档；具体实现细节以仓库源码为准（本笔记未逐行核对仓库，动手实现前应对照源码复核）。

## riddle 是什么

- 那条病毒视频的真身。
- 跑在 **reMarkable 墨水屏**、用 **Rust**、是**文字对话**、**非商用 MIT** 开源。
- 它敢直接叫 "Tom Riddle" ——恰恰反证：我们的**商业版必须原创世界观**。

## 核心可复用智慧（与文字/墨水屏无关，通用）

1. **分工**：AI 只回内容；「像手写/手绘、一笔笔长出来」在本地用**确定算法**做：
   渲染 → Zhang-Suen 抽骨架（瘦成单像素中心线）→ 理笔顺 → 逐笔重播。
2. **流式先落笔**：回复一句句流式返回，第一笔约 1 秒就出现。
   → 我们的处理：文字先流式手写，图像并行生成后再画，盖住图像生成的延迟。
3. **抬笔静置自动成页**（~2.8s），无「发送」键；「墨水淡入纸里」过渡。
4. **出错留在世界观内**：没网/没 key 时，「日记」用它的口吻把原因写在纸上，而不是弹报错。
5. **记忆**：本地纯文件；近几页随请求带上下文；手写指令召回旧页（「给我看看关于花园那页」）；一键遗忘；页数上限。
6. **笔即界面**：尽量少按钮。

## 我们与 riddle 的差异

| 维度 | riddle | Tom Riddle's Diary |
|------|--------|--------------------|
| 载体 | reMarkable 墨水屏 | iPad + 类纸膜 |
| 模态 | 文字对话 | **涂鸦对话**（画进→画回） |
| AI 回复 | 文字 | **文字 + AI 生成图像** |
| 语言 | Rust | Swift / SwiftUI + PencilKit |
| 授权 | 非商用 MIT，直接用 Tom Riddle | 商业向，**必须原创世界观** |

## 对我们的直接启示

- 抽骨架 → 理笔顺 → 逐笔重播这套「本地确定算法」是魔法命根子，先于 AI 做（Task 2-4）。
- 图像也走同一套抽骨架管道（Qwen-Image 生成干净线稿 → 抽骨架），所以线稿提示词要强约束「干净黑线稿、白底、无阴影」。
- 降级、成页、记忆、少按钮这些交互约定直接沿用。
